Тесты на Java: библиотека

Testing in Java: a library

Свой Library API на встроенном HTTP-сервере JDK, без фреймворков, и четыре слоя тестов: REST Assured, WireMock вместо внешнего каталога, Cucumber для правил выдачи книг и Pact между веб-клиентом и API.

A Library API of our own on the JDK's built-in HTTP server, no framework, and four layers of tests: REST Assured, WireMock in place of the external catalogue, Cucumber for the lending rules, and Pact between the web client and the API.

Штраф: где проходят границы

Fines: where the boundaries are

Книга на 14 дней, дальше 0.25 в день, но не больше 10.00. Двигайте ползунок — точки, отмеченные тегом, есть в таблице параметризованного теста. Мутанты M1–M3 ломают именно эти границы.

A book for 14 days, then 0.25 a day, at most 10.00. Move the slider: the tagged points are rows of the parameterized test. Mutants M1–M3 break exactly these boundaries.

02

WireMock: каталог, который подводит

WireMock: a catalogue that lets you down

Каждый тест проверяет две вещи: что ответила библиотека и сколько раз она позвонила в каталог. Выберите поведение каталога.

Each test checks two things: what the library answered and how many times it called the catalogue. Pick how the catalogue behaves.

Cucumber: правило словами библиотеки

Cucumber: the rule in the library's words

Слева сценарий, который может прочитать библиотекарь, справа шаги на Java, которые его выполняют. Имена вроде «Ann» живут только внутри сценария.

On the left, a scenario a librarian can read; on the right, the Java steps that run it. Names like "Ann" live only inside a scenario.

Pact: клиент записывает, сервер подтверждает
Pact: the client records, the server confirms

      
Веб-клиент фиксирует только те поля, которые читает. Тест провайдера для каждого взаимодействия поднимает свежую библиотеку, выполняет @State и повторяет запрос на настоящем сервере.

      
The web client records only the fields it reads. The provider test starts a fresh library for each interaction, runs the @State method and replays the request against the real server.

Посаженные баги
Planted bugs

      
python3 scripts/mutants.py сажает по одному багу и гоняет весь набор — отдельная задача в CI.

      
python3 scripts/mutants.py plants one bug at a time and runs the whole suite, as a separate CI job.
